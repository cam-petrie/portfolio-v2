Case 04 / Full-stack development

Platform

A collaboration platform where members find shared interests, vote on proposals, and turn supported ideas into projects they can join.

Core workflow
Discover → propose → ratify → build

01 / The problem

Make it easier to find work worth joining.

Members needed a way to see who was working on what, find people with shared interests, and turn an idea into a project. I built the explorer, proposal workflow, and member workspaces around that sequence.

The network map uses visible project memberships to connect people and work. Its layout stays stable when a member drags a node, so the rest of the graph remains familiar.

02 / Engineering decision

Make votes and project creation safe to retry.

A double click or a retry after a dropped connection should count as one vote. The database enforces one support record per member and proposal, and counting support and checking whether the proposal has ratified happen in the same transaction.

When the author forms a project from a ratified proposal, a unique link back to that proposal prevents retries from creating a second workspace. The governance tests exercise both SQLite for local development and PostgreSQL for deployment.

03 / What shipped

From a supported idea to a working project.

Members can request to join approved projects and collaborate through project chat and discussion threads. Project leads can manage membership and hand over responsibility.

The hosted platform runs on Kubernetes with PostgreSQL and a separate identity service. Production checks confirmed database readiness and verified the project lead controls in the live app.
